# Mosaic Monitor

Android monitoring app for Mosaic Chain validators and wallets.

## Download and update

Open **Releases** on this repository and download the APK attached to the latest published release. APK files are attached to releases; they are not stored in the source file list.

Android may ask you to allow installation from your browser. Confirm the installation to install or update Mosaic Monitor.

Install updates over the existing app. Do not uninstall the app first: uninstalling can remove locally saved settings, validators and wallets.

Minimum supported Android version: **Android 8.0**.

## Release information

Each release includes its version number, changes and APK. The Android build number increases with every update. Android verifies that an update has a compatible app signature.

Beta releases are test versions. Please report problems through the developer contact and diagnostic log tools in the app.

## Security

Mosaic Monitor does not ask for your wallet recovery phrase or private key. Wallet payments are approved in your wallet app.

This repository distributes the Mosaic Monitor app. It does not contain the application source code, developer credentials or the separate Mosaic Admin app.
