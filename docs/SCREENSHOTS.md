# Mosaic Monitor — Screenshots

[Home](../README.md) · [User guide](USER_GUIDE.md) · [Download](https://github.com/Rolandinfo-ui/mosaic-monitor-releases/releases/latest)

Real screenshots from Mosaic Monitor **1.0.24** on Android. The app supports **English and Hungarian**; these examples use English. Amounts, rates, sessions and dates are snapshots, not current values or a fixed offer. Android's system bars have been cropped; the application content has not been recreated.
